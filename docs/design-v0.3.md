# ソエギ デモ 設計書 v0.3（実装した内容と、v0.2からの改良点）

作成：2026年10月11日。v0.2（10月7日）と「デモ強化と、その先のストーリー（v1）」「デモシナリオ（3本）と導入料金」をもとに実装した結果です。

## 2. v0.2 からの改良点（判断したところ）

### 2-1. 「AIの根拠」をプログラムで確かめる（社内ナレッジ検索）

v0.2 は「Claude の引用（citations）機能で根拠を出す」だったが、デモは DeepSeek なので引用機能が無い。そこで：

1. 資料の各箇所に `[doc_id#section_id]` の印を付けて全文を渡す
2. AI には答えと一緒に「どの箇所の、どの文か（資料から一字一句写した文）」を返させる
3. **Worker 側で、その文が本当にその箇所にあるかを照合する**（全角半角・空白の違いは無視。「…」で省略した引用は、各部分が順に含まれていれば可）
4. 照合できなかった根拠は捨てる。**根拠が1つも残らなければ、AIが「見つかった」と言っても「資料には見当たりません」に置き換える**

→ 原則1（判定はプログラム）に沿い、AIの言いなりで「知ったかぶり」をしない。Claude に切り替えたあとも、この照合はそのまま使える（引用機能に置き換えるかは本番で決める）。

### 2-2. 「必ずリーダーに確認」「要確認」は、AIだけに任せない

- 社内検索：安全・衛生・体調の質問は、AIの判定に加えて**決まった言葉（日本語・英語・ベトナム語・インドネシア語）でも必ず判定**する。根拠が衛生ルール・エラー表などの「安全」の資料なら、それだけでも表示する
- 労務・在留資格（ビザ、残業代の計算など）の質問には、決まった文で「判断できません」を出す
- 「見当たりません」「必ずリーダーに確認」「AIの翻訳です」は、**AIに書かせず、プログラムが言語ごとの決まった文で出す**（6言語＋やさしい日本語）
- 宿：アレルギー・空室・料金・夜の樹氷・送迎の時刻は、問い合わせにその話があれば**AIが挙げなくても「要確認」に必ず出す**（画面に「決まりで必ず表示」）。返信の日本語訳に「安全です」「保証します」などの約束の表現があれば注意を出す
- チャットボット：答えに付けるリンクは、決めた一覧（料金・進め方など）からだけ。それ以外のURLは出さない

### 2-3. 例文のキャッシュ（宿）

用意した例文とよくある質問は、1回目の結果を Cloudflare のキャッシュに30日置き、2回目からはAIを呼ばない（同じ例は毎回同じ結果）。キャッシュに入るのは架空の宿の情報から作った結果だけで、利用者の入力は入れない。プロンプトを変えたら `src/demos/inn.js` の `PROMPT_VERSION` を上げる。

### 2-4. 使いすぎ防止

| 対象 | 制限 |
|---|---|
| すべての API | 同じIPから1分に30回（Rate Limiting バインディング） |
| demo 側のデモ | 合言葉（日本語可。画面側で URL エンコードして送る） |
| 宿の自由入力 | Turnstile ＋ 同じIPから1日5回・500文字まで |
| チャットボット | 同じIPから1日30回・1回300文字まで。履歴は直近6件だけ送る |

1日の回数は KV（`DEMO_KV`）に、**IP をそのまま残さずハッシュにして**、翌々日に消える形で数える。KV が無いときは Worker のメモリで数える（目安）。

### 2-5. 配色はサイトに合わせた

v0.2 12-2 の値と withsoegi.jp の CSS 変数が少し違ったため、「サイトの CSS を正とする」に従ってサイトの値にした。

| 役割 | v0.2 | 実装（サイトの値） | コントラスト |
|---|---|---|---|
| 文字 | `#1A1A1A` | `#1D2327` | 紙の上 14.8 |
| 主ボタン・強調（朱） | `#B7352A` | `#B3243B` | 朱の上の白 6.5 |
| 強調の背景 | `#FBF1EF` | `#F7E7EA` | 薄朱の上の朱 5.4 |
| 面 | `#F4F4F4` | `#F5F7F6`（紙）／`#ECF0EF` | — |
| OK・完了（緑） | `#157048` | `#2E7652` | 緑の上の白 5.5 |
| 要確認 | 黄の背景＋濃い文字 | `#FFF4C7` ＋ `#6B4E00`、必ず「要確認」「注意」の文字も出す | 7.0 |

書体：本文は **BIZ UDPGothic**（v0.2 どおり。外国人スタッフや年配の方にも読みやすいUD書体）、見出しだけサイトと同じ **Shippori Mincho B1**。

### 2-6. 既存デモ（経理・労務）の強化（資料「デモ強化」4章）

- 上に3段階の表示（1 撮る・読み込む → 2 確かめる → 3 Excelにする）。今いる段が朱、終わった段が緑
- 大きな数字：処理件数、かかった秒数、手入力（手計算）なら約◯分（1件あたりの分は画面で変えられる、仮置きと明記）、要確認の件数
- 「御社の場合」の計算：サイトの「元が取れるかの目安」と同じ時給（社長5,000円／事務1,500円／兼任2,000円）と同じ判定の文。結果には必ず「目安です。実際の数字はお試しで測ります」
- 読み取り中は「写真を縮めて、向きを直しています」「AIが日付・支払先・金額を読んでいます」「合計と登録番号を確かめています」と、**実際にしている処理**を出す
- Excel の様式を3つに：標準／仕訳の形／**〇〇会計事務所様式（例）**（10%と8%が混ざったレシートは税区分ごとに行を分け、証憑No.を付ける）
- ボタン名から絵文字とカタカナ語を減らした（「📷 撮る」→「撮る」、「アップロード」は使わない）。ボタンは高さ48px

### 2-7. 料金は1か所に

`public/js/pricing.js` に新しい料金案（初期＋月額、3ヶ月ごとの更新、お試しの5万円を初期費用に充てる）を置き、各デモの最後の一文と、チャットボット（ソエギ版）の知識の両方がここから作られる。

## 3. 決めてほしいこと（実装では決めていない）

1. **サイトの料金の書き方**：withsoegi.jp は今「お試し3万円 → 定着プログラム6ヶ月（初月2万円・合計30万円）→ 卒業」。新しい料金案（お試し5万円、3ヶ月ごとの更新、メニュー別の初期費用）とは、数字だけでなく流れが違う。**サイトを直してからチャットボットを置かないと、ボットとページで料金が食い違う**。直す箇所の一覧は `docs/site-embed.md`
2. 「手作業を減らす（経理・労務）」の料金：新しい料金案に無かったため、v0.2 の「お試し5万円 → 月5万円（3ヶ月ごとの更新）」のままにした。初期費用を付けるか

4. 架空の名前：さくらんぼ食品（仮）、やまびこスーパー（仮）、月山ストア（仮）、道の駅さくらんぼの里（仮）、温泉旅館みずき（仮）、カフェ森のテラス（仮）、ゆきあかり荘（仮）、やまなみ住建（架空）。実在しないかは、こちらでは確かめられていない

## 4. 未確認のこと（ここの環境からは確かめられなかった）

- DeepSeek のモデル名（`deepseek-v4-flash` と `deepseek-v4-flash-vision-exp`）と、手書きの読み取り精度。公式ドキュメントにも API にも、この作業環境からは接続できなかった。`wrangler.toml` の変数で差し替えられる
- 実際の AI での答えの質（台本の質問すべてで根拠が通るか）。モックでは全問通ることをテストで確認済み。本番の AI で根拠が通らない質問は「見当たりません」になる（安全側）ので、公開前に台本の質問を一度ずつ試す
- Turnstile と KV は、Cloudflare 側で作成して設定するまで動かない（無くてもデモは動く。宿の自由入力だけが「準備中」になる）
- 録画（1分）は未作成
