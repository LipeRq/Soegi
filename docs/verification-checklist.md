# 本物のAIでの確認リスト（2026-10-24）

入口に出している7本を、**デプロイ先（Cloudflare・いまは DeepSeek）**で確かめるための手順です。画面と動きは、模擬（`AI_PROVIDER=mock`）で確認済みです。ここで見るのは、**本物のAIが読み取る・書く内容が正しいか**です。

進め方：1本ずつ「やること → 合格の目安」を見て、結果を右の欄（○・△・×とメモ）に書く。×と△は、メモ（画面・入力・出た文）を残して私に渡してください。直します。

- 1回目：いまの DeepSeek で（デモとして使う予定の状態）
- 2回目：`AI_PROVIDER=claude`＋`ANTHROPIC_API_KEY` で（本番の状態。T0 を直したので切り替えられます）。DeepSeek で出た問題が、Claude でも出るか見る
- キーは画面やチャットに貼らず、Cloudflare の環境変数（Secret）に入れる

## 結果の渡し方

×・△の項目は、「どのデモ／入力（画像は添付、個人情報は伏せる）／出た内容／本来こうなってほしい内容」を書いて送ってください。直したら、このリストの結果欄を更新します。
