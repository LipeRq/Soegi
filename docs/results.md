# 成果のまとめ（2026-10-24 時点）

ソエギ デモ（`demo.withsoegi.jp`）のここまでの成果です。ブランチ `claude/stoic-fermat-fqw6or`、Cloudflare の Worker `soegi-demo` に反映済み。AI は当面 DeepSeek（本番で実データを扱う案件のときに Claude へ切り替え。コードは対応済み）。

## 1. 作ったもの

### 入口に出しているデモ（7本）

| 壁 | デモ | 画面 | パスワード | 要点 |
|---|---|---|---|---|
| ① 手入力 | 経理：レシート → Excel | `/receipt.html` | 要 | 写真から読み取り、会計ソフトの取込形式（弥生・MF・freee）も出力。10%/8%の分割・インボイス番号・検算はプログラム |
| ① 手入力 | 労務：残業の集計 | `/attendance.html` | 要 | 打刻CSV・タイムカード写真から、45/80/100時間の区切りで集計。写真は読み取りの確かさを表示 |
| ② 知識 | 社内ナレッジ検索（＋外国人スタッフ向け） | `/knowledge.html` | 要 | 根拠（資料名・行）つきで答える。安全に関わる質問は「必ずリーダーに確認」を先に固定表示。「御社の資料で試す」は Claude 専用（DeepSeek のときは出ない） |

### 業種別の控え（入口には出さず、URL で開く）
- シフト表のチェック `/shift.html`（介護・サービス）
- 注文書 → 受注データ `/order.html`（食品・卸）
- 音声日報 → 報告書 `/report.html`（建設・介護・農業）

### 全デモ共通
- 「御社の場合」の試算（月に浮く時間・月額の元が取れる目安）と、持ち帰り1枚（A4印刷）
- 1週間の記録表（Excel）：お試し前の実測用
- 安全の表示は、画面に固定で先に出す（AI に任せない）

### Webサイト制作の見本（5種類・写真なし・架空）
`/samples-site/`：動きのある新しい見た目／近未来テクノロジー／自然風／お店（パン工房）／車屋。

## 2. 作りの原則（デモ全体）
- AI は「読む・抜き出す・書く」だけ。**判定・計算・安全の表示はプログラム**
- 保存しない（画像・入力・結果）。ログに本文を出さない
- 約束しない（「◯時間削減できます」とは言わない）。登場する会社・人・車はすべて架空
- 色だけに頼らない（色＋言葉・記号）。押す所は44px以上、1画面に主ボタンは1つ
- CSP：インラインのスクリプト・style なし。外部は Google Fonts と Turnstile のみ

## 3. 確かめたこと
- 単体テスト 206件（計算・照合・書き出し・AI の返答の検証・Claude への送り方）
- 画面：390px・800px・1280px で横にはみ出さない・エラーなし（各デモと見本サイト）
- 月次レポートは A4 で1ページに収まる（最悪の長さの名前でも）
- 各タスクで、複数のレビュー（ロジックと画面を別々に）を行い、確認できた指摘を直した。**直していない点は `docs/design-v0.4.md` の各章に記録**

## 4. これから（オーナーの確認が要る）
詳細は `docs/progress.md` と `docs/verification-checklist.md`。
- 本物の AI（いまは DeepSeek）で、入口7本の読み取り・文章が正しいか（チェックリスト）
- 会計ソフトの取込を、各ソフトの試用アカウントで確認（確認したら `VERIFIED` を true に）
- 経過措置 70% が制度として正しいか（税理士・社労士に確認）
- Turnstile のキー、LINE のアカウント、実機のマイク（日報）
- 本番で実データを扱うとき：`AI_PROVIDER=claude` ＋ `ANTHROPIC_API_KEY`（T0 は対応済み、実キーでの確認が残る）
- D1・D2（文書タスク）：内容が未定
