## 3. デモ（demo.withsoegi.jp）で作ったもの

- **入口は3つの壁に整理**
  - 壁①：レシート→Excel（会計ソフト形式：弥生・MF・freee）／残業の集計（紙のタイムカード写真の読み取り強化）／売上CSV→月次1枚レポート
  - 壁②：社内ナレッジ検索（外国人スタッフ向け・引用つき）
  - 壁③：宿の多言語対応（口コミ返信の下書き含む）／サイトのチャットボット（LINE対応）
  - 業種別の控え（シフト表チェック・注文書→受注データ・音声日報→報告書）は、入口には出さず URL のみ
- **共通の考え方**：AIは読む・書くだけ。計算や判定はプログラム。登場する会社・人物は架空。入力した内容は保存しない。約束はしない。
- **AI呼び出し**は `src/ai.js` に集約（DeepSeek／Claude／模擬）。Claude は構造化出力＋サーバー側のフォールバック付き。**本物の Claude キーでの動作確認は未実施**。
- **見本のホームページ5種**（/samples-site/、会社サイトの /sites/ から開く）：動きのある新しい見た目／近未来のテクノロジー／自然を感じる／お店のサイト（パン工房）／車屋のサイト（在庫カード・月々の支払い試算）。写真は使わず、会社・人物は架空。見栄えを上げた版を公開済み。
- **問い合わせフォームの受け口**（`/api/inquiry`）：メールで届く（宛先は2つ、本番で送信確認済み）。サーバーには保存しない。スパム対策あり（見えない入力欄・1日5回まで）。

## 4. 会社サイト（withsoegi.jp）の変更

### 構成
トップを短くし、詳細は下層ページへ：頼むこと（卒業する／使い続ける／必要なものだけ）・料金・デモ・見本・安心のために・事業者概要・お問い合わせ。

### 今回（10/24〜25）の主な変更
- **「安心のために」**：見出しを「AIに社内の書類を預けるということ」に。「絶対に漏れない」とは言わず、**入力の最小化／環境の限定／保管と削除の管理**の3点を運用の基準として記載。
  - 入力を最小に：範囲を着手前に書面で合意／氏名・取引先名・個人情報は匿名化してから入力
  - 環境を限定：学習に使われない設定または法人向けプランのツールだけ（契約前に説明）／事業専用の端末とアカウント／AIの出力は人が検証
  - 保管と削除を管理：作業終了後に削除して報告（月額サービスは終了時に削除）／希望があれば相談段階から秘密保持契約（御社書式も可）
- **代表者・事業者概要**：専門用語を使った書き方に変更（CRM/SFA、要件整理〜設計・実装・効果測定、SQLによる指標の可視化、プロジェクトマネジメント、海外開発パートナーへの指示出し、生成AIの組み込み、リレーショナルDB設計など）。新しい実績は足していない。
  - /about/ には実績カード4枚（2,000万人規模／導入5社・運用9社／生成AI／C#・SQL）を残している。**トップの代表者欄は、カードを外して、名前と一言の紹介だけ**にした。
  - /about/ の長い文章は5段落から4段落に（「測って、決めて、また測る」と重なる段落を外した）。
- **「ご紹介くださる方へ」のブロックを削除**。
- **お知らせ欄**：内容は元の3件のまま（10/12 デモ公開／9/1 ホームページ公開／9/1 無料相談の受付）。スマホでは、1件ずつ区切り線を入れ、日付とラベルの下に本文を置く形に変更。
- **トップの冒頭**：説明文を短縮。「料金はすべてこのサイトに載せています…」の行と、「たとえば…」の行（すぐ下の節と重複）を削除。
- **「お試し導入で、どこまでやるか」**：トップでは通常は閉じておき、押すと「やること／含まないこと」が開く形に。
- **文言を全体的に削減**：トップの各節、詳細ページ（卒業する／使い続ける／必要なものだけ／安心のために／料金／見本／お問い合わせ）の前置き・繰り返しを短くした。数字や条件は変えていない。
- **スマホ表示（特に iPhone の Safari）**：基本の文字を18pxから約16.5pxに下げ、行間・字間を調整。見出しの行の長さをそろえる指定を追加。長い文章は段落の間をあけた。トップの表の折り返し、ヘッダーのロゴが1100〜1240px幅で縦に折れる不具合、料金ページの見出しの二重表示、事業者概要の余白、見出し下の空きも修正。
- そのほか今回までに：問い合わせフォーム（希望日時3つまで・メールで届く）、本文の色を濃く・文字を大きく、業種別の想定の例（工務店・食品・宿・士業）、お試し導入の範囲の定義、「実績が少ない」などの文言削除、ホームページ制作（3万円〜）の追加。

## 7. 運用上の注意（再発防止）

- デモを本番に出すときは、先に別セッションの DeepSeek 修正（思考モードを切る設定）を取り込んでから出す。出さずに出した際は、AI が 400 エラーを返して止まった。
- `wrangler secret put` は即座に新しいバージョンをデプロイする。**コードを先に出してから Secret を入れる**。
- デモ側の手順は `docs/deploy.md`（出す前のチェックリスト・問い合わせ設定を含む）、進捗は `docs/progress.md`。
- 会社サイトの出し方：ステージング用フォルダにサイトのファイルをコピー → `wrangler versions upload` → プレビューで確認 → ご依頼を受けて `versions deploy <id>@100%` → Git の main に反映。本番に出す前に、必ずプレビューを確認してもらう。
