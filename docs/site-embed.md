# withsoegi.jp に足すもの（デモB・C）

サイトの公開方法（Worker「soegi」に4ファイルをアップロードして Deploy）は変えません。`index.html` に次の2か所を足すだけです。
**先に「3. 料金の書き方をそろえる」を済ませてから**、チャットボットを足してください（そうしないと、ボットとページで料金が食い違います）。

---

## 1. チャットボット（デモC）：`</body>` の直前に1行

```html
<script src="https://demo.withsoegi.jp/widget/chat.js" data-profile="soegi" data-mobile-offset="76" defer></script>
```

- 右下に「質問する」のボタンが出ます。サイトのCSSと混ざらないよう、別の箱（Shadow DOM）の中に作っています
- `data-mobile-offset="76"`：スマホ幅（640px未満）でサイトの下に固定の「電話する／無料相談」バーがあるため、その上にボタンを出す高さです
- 呼べるサイトは `wrangler.toml` の `CHAT_ALLOWED_ORIGINS`（既定：`https://withsoegi.jp,https://www.withsoegi.jp`）。ほかのサイトから貼っても動きません
- 答えの中身（サイトの内容）は demo 側の `public/data/sitebot.json` と、料金の `public/js/pricing.js`。**サイトの文章を変えたら、こちらも直してください**（自動では読みに行きません。サイトに無いことを答えないための作りです）
- 確認済み：サイトの `index.html` の写しに貼り、PC（1280px）とスマホ（390px）で開閉・質問・下のバーとの重なりを確認しました

## 2. 宿の多言語対応（デモB）：「たとえば、こんな作業から」の近くにリンク

`#service` の中、「できること、お引き受けしないこと」（`<h3 class="jp-bal">できること、お引き受けしないこと</h3>`）の直前に：

```html
<div class="sub-hd" id="demo-inn">
  <h3>宿泊施設の多言語対応を体験する</h3>
  <p>台湾（繁体字）・英語・韓国語の問い合わせの例を選ぶと、宿のルールどおりの返信の下書きと日本語訳、送る前に確かめる点が数秒で出ます。架空の宿のデモです。</p>
  <p><a class="btn btn-cta" href="https://demo.withsoegi.jp/inn.html">デモを開く</a></p>
</div>
```

- `sub-hd` と `btn btn-cta` はサイトにある既存のクラスです
- デモのページは合言葉なしで開けます。自由入力は Turnstile を設定するまで「準備中」と表示されます（例文はいつでも使えます）

## 3. 料金の書き方をそろえる（判断が必要）

いまのサイトは「お試し3万円 → 定着プログラム6ヶ月（初月2万円）→ 卒業（合計30万円）」の流れで書かれています。新しい料金案（2026-10-11）は「お試し5万円 → 初期費用（お試しの5万円を充てる）＋月額、3ヶ月ごとの更新」で、**数字だけでなく流れが違います**。チャットボットは新しい料金案で答えるので、サイトを先に直す必要があります。

`index.html` で料金・期間に触れている箇所（行番号は 2026-10-11 時点）：

| 行 | 場所 | いまの書き方 |
|---|---|---|
| 7, 12 | `meta description`／`og:description`（検索結果・SNSに出る説明） | お試し 3万円（税抜） |
| 771 | ファーストビューの注記 | お試し導入 3万円／定着プログラム 月5万円 |
| 883 | 「手作業を減らす」の料金 | お試し 3万円、続ける場合は月5万円 |
| 975 | 進め方 3「お試し導入」 | 1業務・1ヶ月、3万円 |
| 993〜994 | 進め方 5「定着プログラム」 | 6ヶ月、月5万円（初月は2万円） |
| 1014〜1100 | 「定着プログラムの6ヶ月」の月ごとの説明 | 1ヶ月目 2万円（お試しの3万円を差し引き）… |
| 1117 | 料金の前置き | 1ヶ月3万円のお試し導入で小さく始めて |
| 1124〜1125 | 料金表 | お試し導入 30,000円／定着プログラム 50,000円／月 |
| 1136〜1141 | 合計の帯 | お試し3万円＋初月2万円＋5万円×5＝合計30万円 |
| 1219 | 「ほかの選択肢と比べて」 | お試し3万円、続ける場合は月5万円×6ヶ月 |
| 1291, 1298 | よくあるご質問 | 6ヶ月を1期／6ヶ月が終わったら |
| 1389, 1396 | ご紹介くださる方へ・紹介文 | お試し導入 3万円、定着プログラム 月5万円×6ヶ月 |

決め方の案：
- **A**：サイト全体を新しい料金案に書き換える（社内ナレッジ検索・宿・チャットボットのメニューを料金表に足す）
- **B**：サイトの「手作業を減らす」はいまの料金のまま残し、新しい3メニューだけを料金表に足す。その場合は `public/js/pricing.js` の `TRIAL` と `MENUS.manual` をサイトに合わせて直す（チャットボットの答えも自動でそろう）

どちらにするか決まれば、`index.html` の差分と `pricing.js` の修正を用意します。
