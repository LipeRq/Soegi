# Instagram：nodus-v30.mp4 の投稿文とハッシュタグ

検索と表示を考えた、30秒の動画（`out/nodus-v30.mp4`）用の投稿文。`ig-day1.md` の②と同じ文にそろえてある。

## 考え方

| ねらい | したこと | 根拠 |
|---|---|---|
| 検索で見つけてもらう | 経営者・事務担当が検索しそうな言葉（業務効率化・業務改善・事務作業・経理・見積書・旅館・中小企業・山形）を、文の中に自然に入れた | Instagram の公式の説明（2021年）：検索は入力された言葉を、ユーザーネーム・自己紹介・キャプション・ハッシュタグ・場所と照らし合わせる |
| ハッシュタグ | キャプションの最後に5個。コメント欄には入れない | 同上：キーワードとハッシュタグはコメントではなくキャプションに。上限5個（2025年12月からと報じられている。公式の原文は未確認） |
| 最初の数行で止めてもらう | 1行目は動画の冒頭と同じ問いかけ。2〜3行目に「何をしてくれるか」 | 長いキャプションは途中で「続きを読む」に折りたたまれるため（何字で折りたたまれるかは未確認） |
| 見てくれる人を広げる | 「事務を担当している方にも共有してみてください」と書いた | 社長から事務担当へ、自然に送ってもらうため（共有が表示にどう効くかは未確認） |
| 場所 | 投稿の「場所を追加」で「山形県」を付ける | 検索は場所とも照らし合わせる（上の公式の説明） |

- 名前、「売り込みはしません」の類、「AI」という言葉、効果を約束する言葉は入れない。
- 対応地域はサイトの事業者概要に合わせる（山形県内は訪問、県外はオンライン）。

## 投稿文（このままコピーして使う）

```
月末、夜まで事務作業が残っていませんか。

レシートの入力、社内の資料さがし、外国語の問い合わせへの返信。
こうした事務の手間を、ITの仕組みで減らす「業務改善」のお手伝いをしています。

できることの例
✔ レシートの写真から、Excelの表へ（経理・記帳）
✔ 社内の資料から、根拠付きで答える（見積書・手順書）
✔ 外国語の問い合わせに、返信の下書き（旅館・ホテル）
読み取りと下書きは自動、計算はプログラム、最後の確認は人がします。何を仕組みにするかは、お話を伺って決めます。

進め方
① 無料相談（60分）
② お試し導入（1つの業務・1ヶ月・5万円・税抜）
③ 作業時間を測って、続けるかを決める

山形を中心に、全国の中小企業（従業員5〜50人ほど）の業務効率化を支援しています。山形県内はお伺いし、県外はオンラインで対応します。

事務を担当している方にも、共有してみてください。
▶ 無料相談は、プロフィールのリンクから

※動画はイメージです。データは架空です。

#業務効率化 #業務改善 #中小企業 #事務作業 #山形
```

## ハッシュタグの選び方

| ハッシュタグ | 役割 |
|---|---|
| `#業務効率化` | 広く検索される言葉。業務改善に関心がある人に届く |
| `#業務改善` | 事業の中身そのもの |
| `#中小企業` | 見てほしい相手（経営者） |
| `#事務作業` | 動画の冒頭の問いかけと同じ悩み |
| `#山形` | 地元の人に届く。場所の「山形県」と合わせる |

投稿ごとに入れ替えて、反応を比べる候補（どれも動画の中身に関係するものだけ）：

- 経理を前に出すとき：`#業務効率化 #中小企業 #経理 #事務作業 #山形`
- 宿を前に出すとき：`#業務効率化 #旅館経営 #インバウンド対応 #山形 #山形の宿`
- 県外にも広げるとき：`#業務効率化 #業務改善 #中小企業 #事務作業 #バックオフィス`

## 投稿するときの設定

1. 表紙：`out/thumb-v30.png` を選ぶ。
2. 場所：「山形県」を付ける。
3. ハッシュタグはキャプションの最後に入れる（コメント欄には入れない）。
4. 投稿したら、プロフィールの上に固定する。
5. 1〜2週間たったら、インサイトで「リーチ」「保存」「シェア」「プロフィールへのアクセス」を見て、次の投稿のハッシュタグを入れ替える。
