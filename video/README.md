# SNS告知動画（Nodus Consulting）

山形を中心に、全国の企業の社長・事務の責任者に向けた、SNS告知動画とサムネイル・投稿文です。HTML で場面を組み、Playwright で1コマずつ画像にし、ffmpeg で mp4 にします。

デモの画面は録画せず、「何ができるか」を動くイラストで見せています（データはすべて架空。サイトの見本と同じ店・会社）。

## できるもの（`out/`）

| ファイル | 中身 |
|---|---|
| `nodus-v30.mp4` | 縦 1080×1920・30秒（リール・TikTok・ショート） |
| `nodus-v15.mp4` | 縦 1080×1920・15秒 |
| `nodus-sq30.mp4` | 正方形 1080×1080・30秒（Facebook・X） |
| `thumb-v30.png`／`thumb-v15.png`／`thumb-sq30.png` | サムネイル |
| `check/<版>-<場面>.png` | 確認用：各場面の、文字が出そろった所の1枚 |
| `check/<版>-cues.json` | 確認用：効果音を鳴らした時刻の一覧 |

投稿文の案は `posts.md`。Googleビジネスプロフィール・Instagram・X の登録内容の案は `profiles.md`。

登録に使う画像（`out/profile/`、`npm run profile-images` でつくる）：

| ファイル | 使う所 |
|---|---|
| `icon.png`／`icon-light.png` | プロフィール画像・ロゴ（1080×1080。丸く切り取られても欠けない） |
| `gbp-cover.png` | Googleビジネスプロフィールのカバー（1920×1080） |
| `x-header.png` | X のヘッダー（1500×500。左下はプロフィール画像で隠れるので、文字は右寄せ） |
| `highlight-1〜5-*.png` | Instagram のハイライトの表紙（1080×1920。中央の丸に絵） |

- 映像：60fps・H.264（High、level 4.2）・yuv420p・CRF 14（見た目で劣化が分からない画質）。
- 音声：BGMと効果音入り。AAC 256kbps・48kHz・ステレオ。音量は -14 LUFS、最大 -1.5〜-2 dBFS 前後（投稿先で再変換されても割れにくい値）。

## 場面（縦30秒）

| 秒 | 場面 | 見せること |
|---|---|---|
| 0〜3 | つかみ | 時計が 18:00 → 22:47。「月末、また夜まで事務作業？」 |
| 3〜6.5 | 困りごと | レシートの入力／社内の資料さがし／外国語の問い合わせ |
| 6.5〜11 | できること① | レシートの写真から、Excelの表へ（1行は要確認 → 最後は人が確認）。効果：入力の手間を減らす |
| 11〜15.5 | できること② | 社内の資料から、根拠付きで答える。効果：探す時間を短く |
| 15.5〜20 | できること③ | 外国語の問い合わせに、返信の下書き（スタッフが確認して送る）。効果：返信までの時間を短く |
| 20〜24 | 進め方 | 削減できた時間を、数字で確かめてから。無料相談 → お試し1ヶ月 → 数字を見て、決める |
| 24〜27 | 地域 | 山形を中心に、全国の企業をご支援します（県内は訪問、県外はオンライン） |
| 27〜30 | 締め | ロゴ・添え書き・無料相談のボタン・URL |

15秒版は、つかみ → できること①〜③（各3秒）→ 締め（「山形を中心に、全国の企業を支援」付き）。

### 守っていること

- 効果は「減らす」「短く」の向きだけを緑の札で示し、「◯時間減ります」などの数字は出さない。数字は「お試しで測ってから」とする（サイトの「削減できた時間を、数字で確かめてから続ける。」と同じ考え）。
- 地図には都市の点や線を描かない。実在しない取引先や実績に見えないようにするため。
- 対応地域の書き方は、サイトの事業者概要（山形県内は訪問、オンラインは全国）に合わせる。
- 「AI」という言葉は使わない（2026-11-17 のコミット `f1b7015` の方針）。光る演出は使わない。

## 名前・URLを差し替える

1. `brand.json` を書き換える。

   | 項目 | 使う所 |
   |---|---|
   | `name` | ロゴ画像が無いときに、文字で出す名前 |
   | `wordmark` | 締めの画面とサムネイルのロゴ画像（このフォルダからの相対パス）。**名前を変えたら、ロゴ画像も差し替えるか `null` にする**（`null` なら `name` を文字で出す） |
   | `url` | 締めの画面のURL |
   | `tagline` | 締めの画面の添え書き |
   | `rep` | 地域の場面の代表名 |

2. 書き出し直す（縦30秒で約2分）。

   ```bash
   cd video && npm install && pip install numpy scipy && npm run render
   ```

3. `posts.md` の名前・URLは、手で書き換える。

## BGM・効果音の出典

**すべて自作です。** `src/make-audio.py` が、外部の音源を使わずに一から合成しています（乱数の種を固定しているので、毎回同じ音になります）。著作権・利用条件の心配はありません。

- BGM：120BPM・ハ長調（Fmaj7 → G6 → Em7 → Am7）。場面の切り替えが拍（0.5秒）に乗る。静か（つかみ）→ リズム → 全体 → 落ち着く（地域の場面）→ 最後の一打、と変わる。流れは `src/render.mjs` の `music`。
- 効果音：切り替え（風切り音）、カード・吹き出し（ポン）、読み取り、表の入力、スタンプ、チェック、送信、地図の波、URLの入力、ボタンの押下（クリックと鐘）。鳴らす時刻は `src/stage.html` の `data-sfx`。

## 部品

| ファイル | 役割 |
|---|---|
| `src/stage.html` | 場面の部品・動き・配置（縦と正方形）と、効果音の時刻。色は withsoegi.jp に合わせてある |
| `src/render.mjs` | 版ごとの場面と秒数・BGMの流れ、書き出し（4並列で1コマずつ撮る） |
| `src/make-audio.py` | BGMと効果音の合成 |
| `src/make-japan.py` | 日本地図（都道府県）を `assets/japan.json` にする。元データは Natural Earth の行政区画（パブリックドメイン）。作り直すときは `ne_10m_admin_1_states_provinces.geojson` を渡す |
| `src/count-x.mjs` | X 用の投稿文の文字数を数える |
| `src/count-profiles.mjs` | `profiles.md` の自己紹介・説明の文字数を数える |
| `src/profile-images.mjs` | 登録に使う画像をつくる |
| `src/pw.mjs` | この環境に入っている Playwright を読み込む |

書体：BIZ UDPGothic、Noto Sans KR、Noto Sans TC（いずれも SIL OFL 1.1、`npm install` で入る）。
