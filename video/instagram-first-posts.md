## 怪しく見せないための決まり

| する | しない |
|---|---|
| 代表の実名・経歴・顔を出す | 誰がやっているか分からないまま宣伝する |
| 料金を先に、全部出す（税抜と明記） | 「お問い合わせください」で料金を隠す |
| できないこと・引き受けないことを先に言う | 何でもできるように書く |
| 効果は「お試しで数字を確かめてから」と書く | 「◯時間削減」「必ず」「絶対」「誰でも簡単」 |
| 情報の取り扱いを具体的に書く | 「安心・安全」とだけ書く |
| 絵文字は ✔ ▶ くらいにする | 絵文字・「！」を多く使う、「今だけ」「先着」「限定」 |
| 実際のお客さまの声だけを、許可を得て載せる | 作った声・実績・ロゴを載せる |
| コメントやDMには、1営業日以内を目安に返す | 返事をしないまま放っておく |
